# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To prepare the Software Requirements Specification (SRS) for a Library Management System and identify the functional and non-functional requirements of the system.
# SRS (Procedure):
1.Identify the purpose and scope of the Library Management System. 

2.Identify the users/actors such as Admin, Librarian and Student/Member.

3.Collect the functional requirements such as login, adding books, searching books, issuing books, returning books and managing members.

4.Identify the non-functional requirements such as security, performance, reliability and usability. 5.Specify the hardware and software requirements needed for the system.

5.Define the inputs, outputs and operations of the system.

6.Document all the requirements clearly in the SRS document. 

7.Review the SRS to ensure that all requirements are complete and understandable.
